# KESCO Complaint Analysis — backend API

FastAPI backend for the KESCO complaint analysis platform (NLP urgency
classification, fault-category clustering, account-level lookup, and
downloadable operations reports). Deployed as a Docker Space.

Set `GROQ_API_KEY` under this Space's **Settings → Variables and secrets**
before use.
